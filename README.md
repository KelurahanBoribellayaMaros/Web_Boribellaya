Sistem Informasi dan Portal Layanan Publik Terpadu untuk Kelurahan Boribellaya, Kecamatan Turikale, Kabupaten Maros. Proyek ini dibangun untuk mendukung digitalisasi pelayanan pemerintah di tingkat kelurahan.

## ✨ Fitur Utama

- **🌍 Profil Kelurahan**: Informasi sejarah, demografi, struktur organisasi, dan potensi kelurahan.
- **📰 Portal Berita**: Sistem manajemen konten (CMS) untuk pengumuman, agenda kegiatan, dan berita terbaru kelurahan.
- **🛠️ Layanan Administrasi (Mandiri)**: Pengajuan berbagai jenis surat pengantar RT/RW secara digital.
- **📊 Keterbukaan Informasi Publik (PPID)**: Akses ke dokumen publik, SOP layanan, dan form pengajuan/keberatan informasi.
- **🔐 Dashboard Admin**: Panel manajemen aman khusus untuk staf kelurahan untuk memantau permohonan, mengunggah berita, dan mengelola dokumen (Didukung oleh Firebase).

## 🚀 Teknologi yang Digunakan

- **Frontend**: [Next.js](https://nextjs.org/) (React App Router) dengan TypeScript.
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [Lucide Icons](https://lucide.dev/).
- **Backend/Database**: [Firebase](https://firebase.google.com/) (Authentication, Firestore, Cloud Storage).
- **Deployment**: Terintegrasi otomatis melalui [Vercel](https://vercel.com/).

## 🔧 Struktur Proyek Singkat
- `/src/app` : Struktur halaman utama Next.js (App Router).
- `/src/components` : Kumpulan komponen antar muka (UI/UX) website.
- `/src/lib` : Utilitas dan konfigurasi koneksi ke layanan pihak ketiga (Firebase, Email, dll).
- `/public` : Aset statis seperti gambar, logo, ikon.
